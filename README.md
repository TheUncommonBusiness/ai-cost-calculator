# AI Model Cost Calculator

An interactive calculator for teams moving a Custom GPT to a third-party platform. Set your knowledge base size, instructions, message lengths, and usage, and it shows the monthly cost across 22 models from Anthropic, OpenAI, Google, xAI, and open-weight providers, plus a recommended setup (whole file vs. retrieval) and three model picks.

- Live site: https://theuncommonbusiness.github.io/tub-ai-cost-calculator/
- Single file: `index.html` (no build step)
- Prices checked October 1, 2026. Update the `MODELS` array in `index.html` when prices change, and bump `PRICES_AS_OF` plus the date in the footer.

Built by The Uncommon Business.
